## Descrição do Projeto

Sistema desenvolvido em JavaScript para gerenciar o estoque de vinhos da **Vinheria Agnello**.

O projeto utiliza **objetos**, **arrays** e **funções de alta ordem** (`map`, `filter`, `reduce`, `forEach`) para organizar e exibir informações sobre os vinhos da vinícola, com saídas via `console.log` e `alert()`.

### Funcionalidades implementadas:

- Cadastro de vinhos com nome, tipo, safra e estoque
- Listagem completa dos vinhos com `forEach`
- Filtro de vinhos com estoque baixo usando `filter`
- Cálculo do estoque total com `reduce`
- Exibição dos nomes em caixa alta com `map`
