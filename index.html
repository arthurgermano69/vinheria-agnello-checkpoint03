Sobre o Sistema:

Este sistema foi desenvolvido para gerenciar o catálogo de vinhos da Vinícola São Roque. Por meio de JavaScript puro, é possível listar todos os vinhos do acervo, identificar vinhos com estoque baixo, calcular o estoque total e exibir os nomes em caixa alta — tudo via console.log e alert().
